# Tech Salary Predictor (India)

Predicting Indian tech salaries from experience, education, location, and skills.

## Dataset

[Indian Tech Salaries](https://www.kaggle.com/datasets/ashishprajapati223/indian-tech-salaries/data)
(Kaggle), ~110k rows. The raw file is messy (inconsistent casing, missing values), so cleaning is the
first step.

## Setup

```bash
pip install -r requirements.txt
```
